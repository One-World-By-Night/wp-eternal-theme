# Docs e tabelas dos autores

Num site com BetterDocs ou TablePress, o tema mantém cada autor no próprio trabalho.

## Quem pode usar

Autores, em sites com BetterDocs ou TablePress, como support.owbn.net. Os administradores do site veem tudo.

## Como chegar

wp-admin → **Docs**, ou **TablePress**.

## A tela

**Docs**

- Um autor vê só os docs, categorias e tags que ele fez.
- As contagens acima da lista contam só os dele.
- O painel do próprio BetterDocs abre a lista simples de docs no lugar.

**TablePress**

- Um autor pode editar e apagar só as tabelas que ele fez.

## Tarefas comuns

### Escrever uma página de ajuda

1. Vá a **Docs** → **Add New**.
2. Escreva-a, escolha a sua categoria e publique.

## Bom saber

- Um doc pertence a quem o salvou primeiro. Ele continua sendo dessa pessoa se outra o edita.
- As categorias e tags que um autor faz também são dele.
- Os administradores do site veem e editam todo doc, categoria, tag e tabela.

## Solução de problemas

- **Um doc ou categoria que você espera não está na lista.** Outra pessoa o fez. Peça a um administrador do site.
- **Você não consegue editar uma tabela.** Outro autor a fez.
