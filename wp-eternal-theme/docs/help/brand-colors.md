# Brand Colours and Dark Mode

OWbN's colours as the theme sets them, and how pages keep them in light and dark mode.

## Who can use this

Anyone who edits pages on the site.

## How to get there

In Elementor, any colour picker → the globe for **Global Colors**.

## The screen

The theme's colours:

- **OWbN red** `#D2242C` - the logo, buttons and accents.
- **Coral** `#EA5B3A` - links and hover states.
- **Burgundy** `#412234` - feature boxes and cards.
- **Dark grey** `#333333` - body text and dark backgrounds.
- **White** `#FFFFFF` - text on dark backgrounds.

**WP Dark Mode** adds the switch readers use to turn dark mode on.

## Common tasks

### Colour something on a page

1. In Elementor, open the element's colour picker.
2. Click the globe and pick a global colour.

## Things to know

- A global colour changes with dark mode; a typed-in code stays the same and can end up dark on dark.
- The site's global colours live in Elementor's **Site Settings**. Change them there, not on single pages.

## Troubleshooting

- **Something is unreadable in dark mode.** It uses a typed-in colour. Switch it to a global colour.
- **No dark mode switch.** WP Dark Mode isn't active, see [Required Plugins](required-plugins.md).
