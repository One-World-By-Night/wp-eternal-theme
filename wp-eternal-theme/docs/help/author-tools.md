# Docs and Tables for Authors

On a site with BetterDocs or TablePress, the theme keeps each author to their own work.

## Who can use this

Authors, on sites with BetterDocs or TablePress, such as support.owbn.net. Site admins see everything.

## How to get there

wp-admin → **Docs**, or **TablePress**.

## The screen

**Docs**

- An author sees only the docs, categories and tags they made.
- The counts above the list count only theirs.
- BetterDocs' own dashboard opens the plain list of docs instead.

**TablePress**

- An author can edit and delete only the tables they made.

## Common tasks

### Write a help page

1. Go to **Docs** → **Add New**.
2. Write it, pick your category, and publish.

## Things to know

- A doc belongs to whoever first saved it. It stays theirs if someone else edits it.
- Categories and tags an author makes are theirs too.
- Site admins see and edit every doc, category, tag and table.

## Troubleshooting

- **A doc or category you expect isn't listed.** Someone else made it. Ask a site admin.
- **You can't edit a table.** Another author made it.
